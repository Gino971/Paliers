# Palier

Simulateur web autonome en français pour expliquer, de façon pédagogique, comment un profil de plongée peut conduire à des paliers.

## Principe

L'application montre :

- la conversion profondeur -> pression absolue
- une limite sans palier simplifiée
- l'estimation d'une charge d'exposition
- la répartition des paliers par tranches de 3 m
- le temps total de remontée

## Utilisation

Ouvre `index.html` directement dans un navigateur moderne.

## Avertissement

Ce projet est éducatif. Il ne doit pas être utilisé pour planifier une plongée réelle.
